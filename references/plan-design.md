## 1. 设计原则

| 原则 | 做法 | 依据 |
|---|---|---|
| 大部分是低强度 | 低强度课次约 75–80%；轻松跑和长距离心率在 LT1 以下 | [TID-1][TID-2][TID-4]；业余跑者两极化和阈值模式差异不大 [TID-5][TID-7]，所以不强求“两极化” |
| 每周 1–2 次质量课 | 阈值（吃力但可控）是主力；间歇（3–5 分钟一组，接近最大心率）少量；马配课放在专项期 | 4×4 分钟高强度间歇能提高 VO2max [WO-1]；精英长跑运动员把阈值训练当作常规内容 [TID-9][TID-8] |
| 长距离逐步加长 | 单次不超过前 30 天最长一次的 110% | [LOAD-3] |
| 周跑量缓慢上升 | 生成器默认每周增加约 8%；超过历史最高周量后每周不超过 5%；减量周之后先回到减量前的水平，再继续加 | 周增幅的研究证据有限 [LOAD-4][LOAD-5][LOAD-6]，所以这是保守的经验做法；对照的是负荷与承受能力的框架 [INJ-3] |
| 定期减量周 | 默认每 4 周一次，跑量降到约 75% | 经验做法；周期化理论本身证据有限，要看个体反应 [PER-1] |
| 周期化 | 基础 → 强化 → 专项 → 减量；专项期加入比赛配速 | 经验做法 [PER-1]；精英实践中常见从金字塔分布逐步转向两极化分布 [TID-8] |
| 赛前减量 | 全马 2–3 周、半马 2 周：跑量逐周连续下降，保持强度和跑步频率 | 最有效的是约 2 周、跑量逐步减少 41–60%、保持强度 [TAPER-1][TAPER-2]；业余全马严格减量 3 周的成绩更好 [TAPER-3] |
| 长距离的长度 | 全马的最长训练一般 28–32 km，或者不超过 3 小时，先到哪个就停 | 最长不到 25 km 的人完赛更慢 [MAR-3]；“32 km 最优”或“3 小时上限”**没有研究证据**，属于经验做法 |
| 力量训练 | 每周 2 次最好（至少 1 次）：基础期一般力量（3×8–12），强化和专项期大重量+跳跃（3–4×4–6 + 跳 3×6），减量期维持，比赛前 10 天停 | 提高跑步经济性 2–8% [STR-1][STR-2]；大重量和组合训练对成绩效果最好，单纯跳跃不显著 [STR-4]；力量训练可以降低运动损伤风险（RR 0.32）[STR-3] |
| 标准有氧检查跑 | 每 4 周（放在减量周）一次：热身 10 分钟 → 固定配速 15 分钟 → 停 60 秒 → 放松 5 分钟；整个周期都用同一个配速和路线 | 固定配速下的心率是证据最好的心率-配速指标，标准化条件下误差最小 [HRP-1]；安排频率是经验做法 |
| 加速跑 | 轻松跑之后做 4–6 次 20 秒“快而放松”的加速 | 爆发力训练能改善 5K 成绩和跑步经济性 [WO-2]；加速跑本身没有直接研究，属于经验做法 |
| 补给演练 | 90 分钟以上的长距离带上比赛同款补给，逐步加到每小时 60 g 碳水 | [FUEL-1][FUEL-2] |
| 稳定骨架 | 每周同一天做同类课，并设好备用日 | 经验做法：减少临时决策，配合“只改今天”的规则 |

## 2. 每周骨架

1. 列出用户每天的可用时间（第 2 步问到的）和事实报告第 5 节的数据（起床时间、开跑时间、每周几跑步）。
2. 按优先级放课：
   1. 长距离放在时间最充裕的那天，通常是周末。
   2. 主质量课和长距离之间至少隔一天。
   3. 第二次质量课（间歇，或者轻松跑加加速）和主课错开。
   4. 主课的第二天放轻松跑或休息日。
   5. 至少 1 个休息日，放在最忙的那天。
   6. 力量训练放在轻松日，或者质量课的同一天（跑完后做），不要放在长距离前一天。
3. 设备用日（`backup`）：主课当天没做，挪到哪天；长距离没做，挪到哪天。只挪一次，过期就放弃。备用日必须在原定日**之后 1–3 天**，并且那天不是另一节重课，通常选力量日、休息日或恢复日。比如周四的主课备用到周五，周六的长距离备用到周日。`today.py` 只会往回找 1–3 天。
4. 时长上限：用户说某天最多 40 分钟，就在请求里写 `"day_max_min": {"wed": 40}`。
5. 把骨架写成表给用户确认后，再生成课表。

示例（5 跑 1 力量 1 休）：
- 周一：轻松跑 + 加速，或者第二次质量课
- 周二：休息
- 周三：轻松跑
- 周四：主质量课
- 周五：力量训练，兼作周四的备用日
- 周六：长距离
- 周日：恢复跑，兼作长距离的备用日

## 3. 用生成器出草稿

请求文件格式见 `assets/plan_request.example.json`。字段：

- `start`：开始日期，自动对齐到周一。
- `race`：`name`、`date`、`distance_m`、`goal_time`。
- `current`：数字都来自 `metrics_latest.json`。`current.vdot` 用事实报告第 6 节的 VDOT（已排除 26 周以前的比赛）；用 `current.race` 时必须写 `date`，超过 26 周 `plan_tool.py` 会直接报错。
  - `avg4_km`：`volume.avg4_km`
  - `max_week_km`：`volume.max_week_km_history`
  - `longest_30d_km`：近 30 天最长一次
  - `hrmax`、`lthr`（或 `lt1`/`lt2`）
  - `race`：近期比赛或测试成绩；没有的话填 `vdot`
- `skeleton`：每天的角色，可选值有 `rest`、`easy`、`easy_q2`（轻松 + 加速，强化/专项期隔周换成间歇）、`quality`、`long`、`recovery`、`strength`。
- `backup`：备用日，例如 `{"thu":"fri","sat":"sun"}`。
- 可选参数：
  - `peak_km`：默认取“历史最高 × 1.15”和“当前 × 1.45”中较小的那个。
  - `weekly_increase`：默认 0.08。
  - `recovery_every`：默认 4。
  - `taper_weeks`：全马 3、半马 2、10K 2、5K 1。
  - `day_max_min`、`easy_max_min`：默认 70。
  - `long_max_min`：全马 180、其他 120。
  - `name_prefix`：写进佳明时课程名的前缀。
  - `aerobic_check_every`：标准有氧检查跑间隔几周，默认 4（放在减量周，测试周除外）；0 表示不安排。
  - `check_pace`：检查跑的固定配速，比如 "5:30"；不填时取轻松配速的快端，并写进 `meta.check_pace`。**以后重新生成课表时，把这个值原样写进请求**，否则前后检查跑不能比较。
- 骨架里某天写成 `"easy+strength"` 或 `"recovery+strength"`，表示当天跑完再做力量；写 `"strength"` 表示只做力量。
- 马配的配速规则：目标配速比当前能力快不到 2% 时，按目标配速练；快得更多时，按当前能力练，检查点达标后再调。

生成器负责：
- 分期：基础、强化、专项、减量、比赛周。
- 每周跑量和长距离进阶，安排减量周。
- 质量课按阶段进阶：
  - 阈值：3×8′ → 3×10′ → 2×15′ → … → 3×3 km。
  - 间歇：5–6×1 km。
  - 马配：3×3 km → 2×5 km → 2×6 km。
  - 专项期隔周安排马配收尾的长距离。
- 检查点测试。
- 剩下的跑量平均分到轻松日，每天都有时长上限。
- 每节跑步课都带结构化步骤，方便导入手表。

生成后一定要人工检查：节假日、出差、比赛日期是否正确；有没有用户明确不能跑的日子；第一周能不能接上用户最近的训练。修改方法见第 4 节。

## 4. plan.json 格式

```json
{
  "meta": {
    "race": {"name": "某某马拉松", "date": "2027-04-18", "distance_m": 42195, "goal_time": "4:00:00"},
    "start": "2026-12-07", "kind": "M",
    "zones": {"hr": {"easy": [100, 143], "long1": [100, 143], "long2": [100, 148], "M": [150, 158], "T": [158, 168], "recovery": [100, 136]},
              "pace": {"E": ["6:05", "6:41"], "M": ["5:35", "5:41"], "T": ["5:00", "5:06"], "I": ["4:33", "4:44"]},
              "vdot": 40.0, "lt1": 148, "lt2": 166},
    "skeleton": {"mon": "easy_q2", "tue": "rest", "...": "..."},
    "backup": {"thu": "fri", "sat": "sun"},
    "name_prefix": "春马·",
    "checkpoints": [{"week": 12, "test": "10K 测试"}]
  },
  "weeks": [
    {"week": 1, "start": "2026-12-07", "phase": "基础", "recovery": false, "target_km": 34,
     "sessions": [
       {"date": "2026-12-10", "type": "threshold", "title": "阈值 3×8′", "km": 9.5,
        "steps": [
          {"kind": "warmup", "km": 2, "hr": [100, 143]},
          {"kind": "repeat", "times": 3, "steps": [
             {"kind": "work", "sec": 480, "pace": ["5:00", "5:06"], "note": "吃力但可控"},
             {"kind": "recover", "sec": 120, "note": "慢跑"}]},
          {"kind": "cooldown", "km": 2, "hr": [100, 143]}]}
     ]}
  ]
}
```

- `type` 的取值：`rest`、`strength`、`easy`、`recovery`、`long`、`long_mp`、`threshold`、`interval`、`mp`、`test`、`race`、`shakeout`。
- 其中 `threshold`、`interval`、`mp`、`long_mp`、`test`、`race` 算高强度，`long`、`long_mp` 算长距离。
- 步骤字段：
  - `kind`：`warmup`、`work`、`run`、`recover`、`cooldown`、`repeat`。
  - 结束条件：`km` 或 `sec`。
  - 目标：心率 `hr: [下限, 上限]`，或配速 `pace: ["快", "慢"]`，二选一，也可以都不写（不设目标）。
  - `note`：会显示在手表上。
- 手改课表时，`km` 要和步骤加起来一致，`title` 要能看出内容。同名课程会在佳明里复用，所以内容不同的课，名字也必须不同。

## 5. 检查规则 P1–P14

`plan_tool.py check` 会逐条检查。`WARN` 要么修改，要么向用户说明为什么保留；`INFO` 是需要留意的提示。

| 编号 | 规则 | 依据 |
|---|---|---|
| P1 | 单次跑量超过前 30 天最长一次的 110%（包括历史长跑） | [LOAD-3] |
| P2 | 周跑量比上一个正常周多 10% 以上（INFO）；比前三周最高还多 30% 以上（WARN） | [LOAD-4][LOAD-5] 证据有限，所以较宽松 |
| P3 | 超过历史最高周量（INFO）；超过 1.25 倍（WARN） | [INJ-3]，经验做法 |
| P4 | 连续 5 周以上没有减量周 | 经验做法 [PER-1] |
| P5 | 一周高强度课超过 2 次，或低强度课次低于 60%；另外统计全计划的低强度占比 | [TID-1][TID-2] |
| P6 | 连续两天都是高强度课或长距离 | 经验做法 |
| P7 | 长距离超过周跑量的 50%（INFO）；预计超过 3.5 小时（WARN） | 经验做法 |
| P8 | 最后两周比最高周少 35–65% 以外；减量期没有强度课；减量期周量中途回升 | [TAPER-1][TAPER-3] |
| P9 | 没有任何测试或检查点；全马计划里 28 km 以上的长距离少于 2 次 | [GOAL-1][MAR-3] |
| P10 | 某一周没有休息日 | 经验做法 |
| P11 | 比赛日没有排比赛；赛前 3 天内还有较重的课 | 经验做法 |
| P12 | 长距离不总在同一天 | 稳定骨架原则 |
| P13 | 备用日不在原定日之后 1–3 天，或者备用日本身是主课/长距离日 | 经验做法；保证“只改今天”能执行 |
| P14 | 力量课的第二天是主课或长距离（按星期汇总）；全计划平均每周力量课少于约 0.75 次 | 经验做法；研究里有效的方案多为每周 2–3 次 [STR-1][STR-4] |

## 6. 怎么向用户解释课表

用 `report-templates.md` 里的“课表说明”模板：
1. 总览：多少周、分几个阶段、周跑量从多少到多少、最长的长距离、检查点。
2. 每周骨架，以及为什么这样排（引用用户的作息数据）。
3. 每种课怎么跑：心率上限优先，配速只作参考；冷、热、风大或疲劳时配速会变慢，不用追。
4. 三条最重要的规则：
   - 轻松跑心率不超过上限。
   - 长距离到时长上限就停，不凑公里。
   - 只改今天，漏掉的课不补。
5. 风险和假设：超过历史最高周量的几周；节假日；你做了哪些假设（比如“假设寒假期间时间更自由”）。
6. 引用的证据编号列表。
